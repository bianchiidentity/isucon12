# ブラウザでたどるISUPORTS

SaaS管理者がテナントを作成し、主催者が選手・大会・スコアを登録、参加者が結果を見て、
主催者が請求と失格を確認する一連のE2E。すべての変更操作は実画面から行う。
APIの応答も同時に確認し、画面だけでは分からない入力行数や403を検証する。

## 実行

ホストPCの443番から練習サーバーの443番へ転送済みの状態で、ホストPCから実行する。
Google ChromeとNode.jsが必要。サーバーにNodeやブラウザを入れる必要はない。

```sh
cd e2e
npm ci
npm test                 # バックグラウンド実行
E2E_SLOW_MO=150 npm run test:headed  # ブラウザで動きを見る
npm run report           # 各手順とスクリーンショットをHTMLで読む
```

テスト専用Chrome内で `*.t.isucon.dev` を127.0.0.1へ解決するため、
テナントを作るたびにhostsを書き足す必要はない。テストブラウザだけ証明書エラーを許容する。
普段使いのChromeの設定は変更しない。

毎回 `e2e-...` という専用テナントを1つ作る。既存テナントの選手・大会は触らない。
削除APIがないため、作ったテナントはそのまま残す。次回の通常のベンチ初期化で削除される。
**ベンチと同時実行しない。** このテストは初期化・サービス再起動・ベンチ実行を行わない。
失敗時の自動リトライはなく、最初の失敗を残す。

## 見る範囲

| 操作 | 検証 |
|---|---|
| テナント作成・ログイン | 新テナントの画面へアクセスできる |
| 選手・大会の追加 | 空の選手一覧、追加後の表示、UUID形式のID |
| 重複選手を含むCSV | 3入力行→2選手、最後の得点を採用、同点は採用行番号順 |
| ランキング・個人戦績 | UUIDのURL遷移、画面の順序・得点、個人戦績の値 |
| CSVの差し替え | 古い選手が消える、不正行で既存結果を維持、ヘッダーだけで空になる |
| 大会終了と請求 | 開催中0円、登録2人＋閲覧のみ1人で210円、繰り返し閲覧・選手の閲覧で二重課金しない |
| 管理者の請求一覧 | 同じテナントの210円が表示される |
| 失格 | 一覧の状態変更、本人の大会一覧・ランキング・個人戦績APIが403 |

「空CSV」は `player_id,score` のヘッダーだけを持つCSV。0バイトファイルとは別。
負荷・並行更新・初期化時間はこのテストの対象外。点数評価には別途ベンチを使う。
UUID導入前の実装で動かす場合だけ `E2E_EXPECT_UUID=0 npm test` を使う。

## 接続先の調整

| 環境変数 | 既定値 | 用途 |
|---|---|---|
| E2E_DOMAIN | t.isucon.dev | アプリのテナント用ドメイン |
| E2E_TARGET_IP | 127.0.0.1 | テストブラウザ内の名前解決先 |
| E2E_HTTPS_PORT | 443 | 例：8443に転送する場合 |
| E2E_BROWSER_CHANNEL | chrome | Playwrightで使用するブラウザ |
| E2E_SLOW_MO | 0 | 操作間隔（ミリ秒） |

## 画面案内の再生成

実行ごとに `../.e2e-artifacts/runs/e2e-.../` へPNGとmanifest.jsonを保存する。
成功した実行を指定してスライドを生成する。

```sh
npm run slides -- ../.e2e-artifacts/runs/e2e-.../manifest.json
```

スライドの画面部分は、その実行で撮影したスクリーンショット。
HTMLレポート・画像・スライドはgitignore対象で、コードのpullに含まれない。
公開するのはスライドと画面PNGのみ。認証Cookieを含み得るtraceやHTMLレポートは公開しない。
