# Issue slides

リポジトリルートの [共通手順](../../../docs/issue-slides/WORKFLOW.md) を読み、実行する。
CodexとClaudeで同じ手順・公開スクリプトを使う。
本文を先に完成させる。「何を変えるか → 今の処理と困る理由 → 具体例 → 変更後 → 難所と現在の実装との差」を、図を見なくても理解できるように書く。図は処理の流れ・データの関係・競合の時間軸を補う。スキル更新だけの依頼では既存Issueや画像を変更・公開しない。
画像はgitignore対象の `.issue-slides/` で生成し、GitHub Releaseへ公開する。
元のissue本文とコードは保持する。図解の依頼だけでベンチやデプロイを行わない。
